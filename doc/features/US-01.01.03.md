# US 01.01.03 — Filtered campsite results

Branch: `US-01.01.03`, based on `US-01.01.01`. Merge the search branch first.

Explore combines the keyword with all supplied criteria and renders a scrollable list with stable document IDs, a result count, an applied-filter summary, and an explicit empty state. Criteria and live record changes immediately recompute the list. Changing criteria returns the list to the top. An optional clear callback lets the filter owner reset its state.

## Section B integration contract

The location/date/guest selection controls belong to US 01.01.02 in section B; they are not implemented by this story. The current navigation uses the default empty filters until that story supplies them to `ExploreScreen`.

Pass `CampsiteFilters(location, guestCount, availableCampsiteIds)` via the screen's `filters` argument, and optionally provide `onClearFilters`. Location matching ignores case and surrounding whitespace. Capacity must be at least the requested positive guest count. For selected dates, section B/C's availability lookup supplies the matching campsite document IDs. `null` means no date constraint; `emptySet()` means no availability and must show no results. No availability is fabricated from incomplete lottery data.
