# US 01.01.05 — Entrant campsite details

Branch: `US-01.01.05`, based on `US-01.01.04`. Merge after summaries.

Details resolve the selected document ID against each live snapshot. They display name, location, amenities, maximum occupancy, price/currency, rating, map coordinates, tags, rules and cancellation policy. Missing optional values have explicit placeholders. Missing, loading and failed records have distinct states with Back and, for failures, Retry. Removal of an open record removes its details from the screen.

Promotional images load through [Coil AsyncImage](https://coil-kt.github.io/coil/compose/) with its [OkHttp network module](https://coil-kt.github.io/coil/network/). A bundled campsite illustration is used for absent, loading and failed images. Coil is pinned to 3.2.0, compatible with this project's Kotlin compiler; no compiler upgrade is required.

The Firestore mapper retains the team's existing legacy aliases and accepts `price` (or `pricePerNight`), optional `currency`, `rules`, and `cancellationPolicy`. Old records remain readable. Registration/editing of these fields belongs to the owner form stories; this change does not fabricate missing values or assume a currency.

Validation: all 30 JVM tests pass, including full and legacy document mapping and missing/zero/invalid prices. App and instrumented-test APK builds pass. `CampsiteDetailsTest` covers full details, the missing-image placeholder, changed records, removal, loading and retry; compiled but not run because the emulator exits before boot. Live Firebase access and remote-image success still need a device smoke check.
