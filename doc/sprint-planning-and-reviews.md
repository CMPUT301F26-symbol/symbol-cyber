## Plan at the start of each sprint

Use the [weekly planning and review template](https://github.com/CMPUT301F26-symbol/symbol-cyber/blob/main/doc/sprints/TEMPLATE.md). Save the actual planning date, sprint goal, specific story IDs, a named owner for each, and dependencies before implementation begins. Preserve the initial plan and append later scope changes with their actual dates.

## Record the lab review

Record the actual date, TA mentor and every member's attendance. For each demonstrated story, record the tested revision/device, observed result, TA feedback and decision, and a named owner for follow-up. Keep implementation status, issue state and TA acceptance separate. Carry unfinished stories into the next dated sprint explicitly.
